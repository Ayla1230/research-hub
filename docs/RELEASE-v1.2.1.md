# Research Hub v1.2.1

這是第一個包含下列新功能的版本。先前發佈的 v1.2.0 是在功能合併前建立的，內容仍是舊版，請改用 v1.2.1。

從 v1.1.0 或 v1.2.0 升級：直接用新版開啟原本的工作區即可，新的欄位與資料表會自動補上，既有資料不會變動。

## 新功能

### 導覽
- 左上角三條線選單列出五個區塊（總覽與研究流程、研究核心、考題與申論、整合中心、動態紀錄），一次只顯示一個區塊。
- 上方只列出目前區塊的細項；設定與語言切換移到選單底部。按 `m` 開選單。

### 研究核心
- **題目強度檢測**：像密碼強度分「簡單／中間／難」。斷詞、中文題目自動翻英文、到 OpenAlex 分台灣與國外比對重疊度，並檢查題目有沒有原因和故事。
- **研究設計檢核**：投稿前五個研究設計問題、因果推論四要件、控制變數三項判斷（Bono & McNamara, 2011），依變數的測量來源與時點自動提醒。
- **PROCESS 模型範本**：依 Hayes PROCESS 的模型編號提供 56 個模型（Model 1–22、28、29、58–76、80–92），可預覽概念圖並一鍵套用到研究架構圖，支援三階交互作用與多個中介。

### 考題與申論（新區塊）
- **由上傳的論文檔案出題**：PDF、.docx、.txt，產生申論題與答題架構，勾選後存入題庫。
- 考題整理與文獻整理（資料夾）、考題預測、考題解析、文獻解析。
- **申論模擬練習**：計時作答，交卷後依答題架構涵蓋率給分。
- **練習紀錄與弱點分析**：保留歷次分數，依主題找出最弱的部分。
- **複習排程**：依分數安排下次複習，「今天該複習」列出到期的考題與文獻。
- 內附 16 題研究方法範例題庫。

### 匯出
- **論文 Word 檔**：封面、誌謝、摘要、目錄／圖目錄／表目錄（頁碼 i、ii、iii）、第一至三章（頁碼從 1 起）、APA 參考文獻。內文樣式名稱為「論文設定0」，字型、字級、行距、邊界可設定。
- **語音 Podcast**：把研究故事、文獻筆記或考題解析轉成語音，可選聲音、語氣、語調、速度，匯出 WAV。

## 使用前請注意
- **題目重疊比對**會把題目送到 OpenAlex 與翻譯服務（MyMemory）；取消勾選「連線比對」可改為離線，此時最高只顯示「中間」。OpenAlex 對台灣中文學位論文收錄有限，定題前仍請查臺灣博碩士論文知識加值系統。
- **PROCESS 範本**的概念圖由系統依模型結構繪製。Model 13–16、19、20、60–92 已對照 Hayes 附錄 A；其餘模型未逐一對照，正式分析前請對照 Hayes (2022)。路徑多的模型（如 80、82）預覽圖的線會重疊，請以文字列出的路徑為準。
- **PDF 出題**以 Poppler 的 `pdftotext` 讀取最完整；沒有安裝時只能讀單純的英文文字 PDF，掃描檔或中文 PDF 請另存 .docx。
- **語音匯出**使用電腦內建語音：macOS 與 Windows 內建，Linux 需安裝 `espeak-ng`。只輸出 WAV。
- **Word 目錄頁碼**：開啟後在目錄按右鍵「更新功能變數」才會出現。
- **規則式出題與評分**是關鍵詞比對：分數反映有沒有寫到重點，不代表寫得好不好；要貼近內文的題目與講評需在設定填 AI 金鑰。

## 安裝
需要 Python 3.10 以上，不需安裝其他套件。下載後執行 `start.sh`（macOS／Linux）或 `start.cmd`（Windows）。
