# Research Hub v1.2.5

新增「緒論檢核」：依 Grant & Pollock (2011)〈Setting the hook〉檢查緒論。

從 v1.2.4 升級：直接用新版開啟原本的工作區即可，資料不會變動。

## 新功能
- **緒論檢核分頁**（研究核心）
  - 研究初衷：先寫下為什麼做這個研究，整篇緒論都要回到這句話。
  - 緒論要回答的三個問題（Who cares？What do we know / don't we know / so what？What will we learn？），直接對照 5C 句子。
  - 自動檢查審稿人最常指出的三種錯誤：未能激發動機與問題化、缺乏焦點（含故事線是否連貫）、過度承諾。
  - 開場方式、建立與問題化文獻（不完整性／不足性／不相容性）、預告貢獻（改變共識／建立共識）、重寫方法。
  - 緒論草稿：檢查微型摘要五要素，可存成新版本記錄重寫次數。
- **上傳論文時自動擷取第一章緒論**填入緒論草稿（草稿空白時）。
- **考題庫新增 4 題**：緒論三個問題、三種問題化策略、三種常見錯誤、改變／建立共識。

## 使用前請注意
- 檢查是關鍵詞比對，會誤判；例如換句話說時，「故事線不連貫」可能誤報。
